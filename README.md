## Tech
Spring Boot, Spring Data JPA, PostgreSQL, Java 17.

## How to run
1. Create a PostgreSQL database named wifi_requests.
2. In PowerShell set the password: $env:DB_PASSWORD="your_password"
3. Run: .\mvnw spring-boot:run
4. The API starts on http://localhost:8087

## Postman
Import school-wi-fi-password-request-system-midterm.postman_collection.json.
One request per requirement, named by its ID.
